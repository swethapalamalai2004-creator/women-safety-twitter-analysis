# Analysis of Women Safety in Indian Cities Using Twitter Data

## Project Overview

This project analyzes women safety-related Twitter data using Python.

The system performs tweet preprocessing, sentiment analysis, and visualization to understand opinions related to women safety.

## Technologies Used

- Python
- Pandas
- NumPy
- TextBlob
- NLTK
- Matplotlib
- Folium
- Tkinter

## Features

- Twitter dataset loading
- Tweet text preprocessing
- Sentiment analysis
- Positive, Negative and Neutral classification
- Sentiment visualization using a pie chart
- Heatmap visualization

## Dataset

The project uses a CSV dataset containing a `Text` column.

The current dataset contains 2000 synthetic/demo tweet-like records created for testing the application.

## Project Output

The application produces:

- Sentiment analysis results
- Sentiment pie chart
- `heatmap.html` interactive visualization
